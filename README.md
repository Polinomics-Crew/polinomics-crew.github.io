# The Polinomics Crew

The day's politics and economics, told at ten reading levels, from in-depth to the basics.
Presented by Wilf Brown, Ollie Robinson and Rohan Down. Listen to the podcast on [Spotify](https://open.spotify.com/show/4yAAH950nzI5bn1M0CdtlJ).

- `index.html` is the whole site.
- `data/` holds today's stories and the crew's articles, refreshed each morning.
- `build.py` rebuilds `data/` from an export of the Polinomics app.

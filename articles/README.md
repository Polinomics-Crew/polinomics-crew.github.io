# Crew articles

Upload your articles here and they'll appear on https://polinomics-crew.github.io within half a day, written at all ten reading levels.

## How to add one

1. In this folder, click **Add file**, then **Create new file** (or **Upload files** for a text file or Word document).
2. Name the file after the article, e.g. `labour-conference.md`.
3. Write it like this:

```
Your headline goes on the first line
By: Wilf Brown

Your article starts here. Leave a blank line between paragraphs.
```

4. Click **Commit changes**.

The site checks for new articles at about 7am and 6pm UK time. To change an article, edit its file; the site will update at the next check. To take one down, delete its file.

The byline must be one of: Wilf Brown, Ollie Robinson, Rohan Down.
